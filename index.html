Projects

Simulation

delphi-sim-pipeline

Plugs any modern event generator into the DELPHI detector simulation. The generator-agnostic hepmc2fadgen turns a HepMC3 record into the Fortran-unformatted LUJETS dump (fort.26) that DELSIM reads; DELSIM and DELANA then produce standard shortDST and fullDST. Pythia 8, Sherpa, Herwig 7, Whizard, KKMCee and external HepMC3 are wired in, with container and HTCondor tooling and reproducible seeding.

Use it when you want to generate new Monte Carlo events and push them through the real DELPHI simulation and reconstruction.

Repository

Conversion

delphi-edm4hep

Converts DELPHI ZEBRA reconstruction data into podio/EDM4hep. A two-pass C++ pipeline writes shortDST content as sDST_* collections, then matches the fullDST events and adds detailed fDST_* collections — reconstructed particles, track states and covariance, vertices and beamspot, calorimetry, particle identification, generator truth and reco-to-truth links.

Use it when you have DELPHI shortDST/fullDST data or simulation and want an analysis-ready EDM4hep representation with documented collection meanings and units.

Visualisation

delphi-edm4hep-eventdisplay

Draws a DELPHI event straight from an EDM4hep file — no DELGRA, no X11, no ROOT. Four panels (r-φ, r-z, the vertex detector, RICH Cherenkov angle against momentum) or a 3-D detector scene. Collections are discovered from podio metadata rather than assumed, and every one in the event is listed beside the figure with its type, domain, provenance, links and object count. It runs in the browser: drop a file on the page and uproot reads it locally under Pyodide — nothing is uploaded.

Use it when you want to look at a single converted event, see what a collection really holds, or make a figure for a talk.
